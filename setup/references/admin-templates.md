# Admin Templates

Use when creating Admin archetype files (TODO.md, GOALS.md, LOG.md, inbox/, outbox/, etc.).

---

## TODO.md (Admin)

```md
# Tasks

## Current
- [IN_PROGRESS] Initial setup

## Backlog
- [TODO] Define goals and success criteria

## Done
(none yet)
```

---

## GOALS.md

```md
# Goals

## Objective
[What we're trying to accomplish]

## Success Criteria
- [ ] Criterion 1
- [ ] Criterion 2

## Deadline
[Date or "no hard deadline"]

## Constraints
- Budget: [if applicable]
- Dependencies: [external factors]

## Scope

### In Scope
- (to be defined)

### Out of Scope
- (to be defined)
```

---

## NOTES.md

```md
# Notes

Research findings, decisions, and reference information.

---

## [Topic]
**Date:** YYYY-MM-DD

[Content]
```

---

## LOG.md

```md
# Activity Log

Chronological record of project activity.

---

## YYYY-MM-DD
- Project initialized
```

## inbox/MANIFEST.md

```md
# Inbox Manifest

Documents received for this project.

| File | Description | From | Received | Status |
|------|-------------|------|----------|--------|
| (none yet) | | | | |

## Status Legend
- **Pending** — Received, not yet reviewed
- **Reviewed** — Reviewed, no action needed
- **Processed** — Data extracted/used
- **Action Required** — Needs response or follow-up
```

## outbox/MANIFEST.md

```md
# Outbox Manifest

Documents sent for this project.

| File | Description | To | Sent | Confirmed |
|------|-------------|-----|------|-----------|
| (none yet) | | | | |

## Confirmation Status
- **Yes** — Delivery confirmed or acknowledged
- **Pending** — Sent, awaiting confirmation
- **N/A** — No confirmation expected
```
